<h3>About this app:</h3>
<div>This app allows you to create and manage countdown events for your favorite games, anime releases or importants like go to Doctor. You can add events with titles, descriptions, dates, associated game or anime names, repearing the events, skip the DND/Silent, notify before each time and more functions for crate the events more comfortable and greatable.<br>
The events will be displayed with a live countdown timer and notify for events.<br></div>
<div>This app is gen by AI and web codded by ArthurVesta(MNTS) and is open source.</div>
<br>
<h3>Features:</h3>
<div>Export events in .json file.</div>
<div>Import events from .json file [<!>This feature will replace existed events that edited after export the .json, e.g. event edidet with id 5 will replaced by same id(5) stored in .json].</div>
<div>Ignore DND and Silent setting in Edit/Create event for set the events IMPORTANT for hear them at DND or Silent</div>
<div>Search between events.</div>
<div>Bright/Dark Themes.</div>
<div>Add link to source site.</div>
<div>Do repeated events by day, month, year or per N days.</div>

<h3>О этом приложении:</h3>
<div>Это приложение позволяет создавать и управлять отсчетом времени для ваших любимых игр, релизов аниме или важных событий, таких как визит к врачу. Вы можете добавлять события с названиями, описанием, датами, привязанными названиями игр или аниме, повтором событий, обходом режимов «Не беспокоить» / «Тишина», уведомлениями заранее и множеством других функций для более удобного и полного настройки событий.<br>
События отображаются с живым таймером обратного отсчета и системой уведомлений.<br></div>
<div>Это приложение создано с помощью ИИ и запрограммировано для веб разработчиком ArthurVesta (MNTS), а также имеет открытый исходный код.</div>
